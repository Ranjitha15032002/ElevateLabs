# 🚢 Titanic Data Preprocessing

This project demonstrates data cleaning and preprocessing on the Titanic dataset using Python. The dataset is prepared for machine learning by handling missing values, encoding categorical data, scaling features, and removing outliers.

## 🔧 Steps Performed

- ✅ Handled missing values (`Age`, `Embarked`, `Cabin`)
- 🧠 Encoded categorical features (`Sex`, `Embarked`)
- 📏 Standardized numerical columns (`Age`, `Fare`)
- 📉 Visualized and removed outliers using boxplots (IQR method)
- 🧹 Dropped irrelevant columns (`PassengerId`, `Name`, `Ticket`)

## 🛠️ Tools Used

- Python, Pandas, NumPy, Seaborn, Scikit-learn

## 📁 Files

- `titanic.csv` – Original dataset  
- `titanic_cleaning.ipynb` – Jupyter notebook  
- `titanic_cleaned.csv` – Final cleaned dataset
